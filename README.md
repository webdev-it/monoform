# MONOFORM

Самостоятельный статический сайт из коллекции портфолио. Ничего не нужно устанавливать или собирать.

## Запуск

Откройте `index.html` или запустите в этой папке:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000 .

## Vercel

1. Создайте отдельный репозиторий из содержимого этой папки либо используйте папку как Root Directory в общем репозитории.
2. Импортируйте репозиторий в Vercel.
3. Framework Preset: Other. Build Command: пусто. Output Directory: `.` (корень проекта).
4. Опубликуйте. Все изображения и шрифты локальные, сторонние CDN не используются.

## Структура

- `index.html` — контент и семантическая разметка.
- `base.css`, `style.css` — общие компоненты и уникальный дизайн проекта.
- `base.js`, `app.js` — доступные диалоги, мобильное меню и логика проекта.
- `assets/` — созданные изображения, графический логотип и локальные шрифты.
- `vercel.json` — настройки статической публикации.

## Честные границы демо

Вымышленный бренд, концептуальный проект. Сервер, оплата, реальные заказы, отправка писем и авторизация не подключены. Формы скачивают локальный текстовый бриф; интерфейсы не имитируют успешную отправку. Состояние корзин и задач хранится только в localStorage браузера. Не вводите чувствительные данные.

## Изменения

Редактируйте тексты в HTML, цвета в переменных `style.css`, поведение в `app.js`. Ничто не зависит от других папок коллекции.
